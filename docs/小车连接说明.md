```sh

```

## Mihomo后台代理

树莓派已安装Mihomo v1.19.34，服务设为开机启动。

在小车终端管理服务：

```sh
systemctl status mihomo.service --no-pager
sudo systemctl restart mihomo.service
sudo systemctl stop mihomo.service
journalctl -u mihomo.service -b --no-pager -n 50
```

配置文件位于 `/etc/mihomo/config.yaml`；本机HTTP/SOCKS混合端口为 `127.0.0.1:7890`，控制API为 `127.0.0.1:9090`，仅回环可访问。

## 树莓派上的Codex CLI

已安装原生ARM64版本0.167.2，无需Node.js/npm。以下命令在小车SSH终端执行：

```sh
codex --version
codex-proxy login --device-auth
```

`codex-proxy`是本机辅助入口，通过Mihomo的127.0.0.1:7890访问网络，仅影响该进程及子进程；普通codex命令保持原生网络行为。设备码登录需要用户在浏览器打开CLI给出的官方链接并完成登录，不要把登录码或凭据贴到聊天。若账号未启用设备码登录，需按官方账户设置开启或使用SSH转发登录方式。

登录完成后，进入小车上的实际项目目录，执行：

```sh
codex-proxy
```

退出交互会话后可检查登录状态：

```sh
codex login status
```

安装位置为 `/home/pi/.local/share/codex/releases/0.167.2/`，命令在 `/home/pi/.local/bin/`。不需要sudo启动Codex。当前只验证程序和命令可运行，尚未替用户登录或进行模型调用。
