# 比赛场地模型

依据 2026-11-17 组委会〔2026〕1 号区赛参考细则赛题 1 图 1。世界原点为甲队发车侧的左下内角，X 向右、Y 向上，坐标单位为米。PNG 顶行对应 Y=2 m。

| 区域 | 外形 | 左下角坐标（mm） |
| --- | --- | --- |
| 围挡内净场地 | 3000 × 2000 | (0, 0) |
| 甲队球门 | 400 × 600 | (0, 700) |
| 乙队球门 | 400 × 600 | (2600, 700) |
| 甲队发车区 | 300 × 300 | (50, 50) |
| 乙队发车区 | 300 × 300 | (2650, 1650) |
| 中央摆棋区 | 600 × 600 | (1200, 700) |

四周挡板高 300 mm，模型使用向外布置的 20 mm 厚挡板，维持内净尺寸。发车区距相邻围挡的 50 mm 留边按示意图取值。地面配色从示意图近似，线宽、虚线节距是建模值。所有区域与赛面齐平。

- `field.svg` 是 1:1 矢量喷绘图，单位 mm。打印前核对输出比例。
- `field.png` 是无文字贴图，3000×2000，1 mm/像素。
- `field.obj` 是带 UV 的场地表面，`field.glb` 是带贴图与围挡的完整模型，单位 m。
- `preview.png` 是带尺寸的预览，`field.json` 是区域坐标和尺寸的数据源。

在仓库根目录用装有 Pillow 和 trimesh 的 Python 重建：

```sh
python assets/field/build_field.py --label-font /absolute/path/to/CJK-font.ttc
```

MuJoCo 从 `field.json` 读取围挡和区域尺寸，主仿真入口生成中央区内的 32 枚无重叠棋子。该入口仍用于单车流程验证，推棋比赛的阵营加权、双车对抗和终场判分另行实现。
