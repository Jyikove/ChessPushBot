# 比赛棋子模型

规格依据 2026-11-17 组委会〔2026〕1 号区赛参考细则的赛题 1 与棋子附件。70 号双面棋，公称直径 **67 mm**、厚 **17 mm**。甲队黑底红字，乙队黑底白字，每队 7 个棋种、16 枚、理论合计 45 分。每枚正反面用同一个字和颜色，翻面后字形可正常阅读。

`chess.json` 记录尺寸、颜色、每种棋子的数量和分值。字形由通知 PDF 第 8 页约 70 像素的原始嵌入图描摹，分别保留红字与白字的原笔画，清掉压缩杂点并平滑轮廓。环线按原图测得的比例圆化。外轮廓仍是从低分辨率图片重建的近似，圆边、浅刻深度和图案在实物上的印刷尺寸均待现场复核。

红字轮廓同时参考原图的亮度和色彩。候选轮廓在去掉环线的区域内，用原图像素尺度的相关性筛选，同时约束笔画覆盖面积，避免低清图的边缘晕染合并细笔画。

红字采用 F 档，笔画名义宽度收窄 1.20 mm。白字采用 E 档，笔画名义宽度收窄 0.90 mm。轮廓沿每侧各内收名义宽度减量的一半，环线沿用原比例。

| 文件 | 含义 |
| --- | --- |
| `step/` | 14 个可编辑实体，单位 mm，双面浅刻 |
| `stl/` | 对应 14 个单体打印网格，单位 mm。STL 不含颜色 |
| `glb/` | 14 个带黑色棋身、红/白字符和环线的带色模型，单位 m |
| `collision.stl` | 简化圆柱包络，单位 mm |
| `preview.png` | 14 种棋面的数量、分值与字形预览 |
| `faces/` | 14 张 PDF 原始嵌入图片和页码、对象编号、原件哈希 |
| `faces_hd/` | 14 张经修复的棋面，每种含可缩放 SVG 和 1024×1024 透明背景 PNG |
| `../../sim/resources/chess/` | 反应式仿真共用的带色几何与实例清单，网格以圆柱中高为原点，单位 m |

在仓库根目录运行以下命令重新生成。需要 Python 的 cadquery-ocp、NumPy、SciPy、contourpy、Shapely 2、Pillow 和 trimesh。参数 `--label-font` 只用于预览标题和标签，棋面的文字和环线由 PDF 图像生成。

```sh
python assets/chess/build_chess.py --label-font /absolute/path/to/BiauKai.ttc
```

如果需要重新从原通知提取图片，用有 PyMuPDF 的 Python 运行：

```sh
python assets/chess/extract_pdf_faces.py /absolute/path/to/notice.pdf
```

MuJoCo 碰撞圆柱使用半径 0.0335 m、半高 0.0085 m，配套放置高度、间距和整体入区几何读取同一份规格。仿真继续使用原来的假设质量，正式双车计分与新棋训练数据需另外对齐。
